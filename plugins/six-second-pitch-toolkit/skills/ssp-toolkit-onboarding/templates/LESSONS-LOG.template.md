## How a lesson gets logged (the loop)
1. You correct the crew on something.
2. If it's the **second time** for the same thing → it's a pattern. Log it here.
3. Write the **permanent fix** into the source: a House Rule (Operating Manual), a brief item
   (Requirements), or — if it's about how a tool behaves — note it for the tool's own fix list.
4. From then on, the crew reads the fix at the start of every session. Problem solved once, not weekly.
